# Dynamic Context Compression

- Module : `dynamic-context-compression`
- Statut : `PARTIALLY_DEFINED`
- Sources : `SRC-0003`
- Valeur normative en v0.1 : `false`

## Modèle d'exécution

Cycle, déclencheurs, concurrence, reprise et conditions d'arrêt non stabilisés.

## Garde

Ne pas transformer un enchaînement narratif en machine à états exécutable sans contrats de transition.
