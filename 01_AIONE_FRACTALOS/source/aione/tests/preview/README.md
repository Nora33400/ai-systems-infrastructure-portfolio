# Private Preview Tests

These tests are preview readiness scaffolds. They must not publish AIONE, install dependencies silently or modify system configuration.

Required manual flow:

1. create a disposable workspace or clean Windows profile;
2. run startup scripts;
3. open Forge UI;
4. open Windows HUD;
5. run private preview E2E;
6. capture evidence;
7. keep preview status blocked until all critical gates pass.
