# xconcept-error-engine

Moteur simple de gestion d erreurs contextuelles (A/B/C) pour pipeline IA.

## Demo

```bash
python main.py --sigma '{"mu":0.62,"kappa":0.5,"rho":0.3,"epsilon":0.7,"delta":0.65,"lambda":0.7}' --contradictions 1
```
