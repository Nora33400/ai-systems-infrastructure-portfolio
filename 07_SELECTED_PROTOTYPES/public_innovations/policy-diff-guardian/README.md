# policy-diff-guardian

Démonstrateur de diff réglementaire: compare deux politiques et extrait obligations/interdictions/risques.

## Demo

```bash
python main.py --base base_policy.txt --candidate candidate_policy.txt
```

Sortie: `reports/policy_diff_report.json`.
