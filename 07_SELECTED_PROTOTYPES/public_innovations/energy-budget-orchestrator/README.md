# energy-budget-orchestrator

Démonstrateur d'orchestration sous budget énergétique (CPU/GPU simulé) avec sélection optimale de tâches.

## Demo

```bash
python main.py --watt-budget 260
```

Sortie: `reports/energy_plan.json`.
